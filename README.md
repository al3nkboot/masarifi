# مصاريفي — Masarifi

تطبيق أندرويد لإدارة المصاريف الشخصية (Kotlin، Jetpack Compose، Material 3، Room). واجهة عربية (RTL) افتراضيًا مع دعم الإنجليزية، والعملة الافتراضية الريال العُماني (ر.ع.).

## المزايا
- تسجيل المصروفات والدخل والتحويلات بين الحسابات، مع تصنيفات قابلة للتعديل.
- قراءة رسائل SMS البنكية العُمانية تلقائيًا وتحويلها إلى معاملات (قواعد قابلة للتخصيص).
- ربط البطاقات بالحسابات من الإعدادات (البنك + آخر 4 أرقام → الحساب)، تُحفظ على الجهاز فقط ولا توجد أرقام حقيقية في الشيفرة.
- دمج الرسالتين المكررتين لنفس العملية (مثل بنك ظفار: رسالة الحساب ورسالة البطاقة)، وتحويل التحويلات بين حساباتك (مثل بنك مسقط ← بطاقة موجب) إلى عملية تحويل واحدة، وتسجيل السحب من الصراف كتحويل إلى النقد.
- أداة «إصلاح العمليات التلقائية» لمراجعة العمليات القديمة وتصحيحها مع إمكانية التراجع.
- كشف المعاملات المكررة، والمعاملات المتكررة، والميزانيات مع تنبيهات 80% و100%.
- إحصائيات ورسوم بيانية ونصائح ذكية حول الإنفاق.
- استيراد من تطبيق Money Manager ‏(xlsx/CSV)، ونسخ احتياطي واستعادة، ومزامنة بين الأجهزة.

## البناء
```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # اختبارات الوحدة
```
يتطلب Android SDK و JDK 17. التوثيق التفصيلي بالإنجليزية في `docs/README.en.md`.

> جميع بيانات الاختبار وهمية. بعض اختبارات استيراد xlsx تحتاج ملف العينة المُولَّد عبر `python3 tools/gen_mm_fixture.py`.
